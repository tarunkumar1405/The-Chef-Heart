# The Chef's Heart – Bakehouse (proposed starter website)

A responsive static homepage for The Chef's Heart – Bakehouse, Hapur, Uttar Pradesh.

## Files
- `index.html` — homepage content and metadata
- `style.css` — responsive styling in cream, chocolate brown and gold
- `script.js` — mobile navigation, product enquiry buttons and dynamic footer year
